# CalcFlow

A mobile-first, installable calculator super-app. Broad calculator library,
original visual identity, modern mobile UX, and a fully working calculation
engine. See `BUILD_CALCFLOW.md` for the full product/build spec.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Testing

```bash
npx vitest run
```

## Status

Phases 1–3 complete: foundation (design system, theming, routing, PWA
baseline, calculator architecture), core UX (Home, Search, Categories,
Favorites, History, Settings), and 8 working calculators (Percentage, Tip,
BMI, Age, Mortgage, Loan, Compound Interest, Scientific).
